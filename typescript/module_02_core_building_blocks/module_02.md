# Module 2 — Core Building Blocks: Types, Annotations, Inference

## Opening Analogy
Every material on a blueprint carries a stamped label — this stud is
timber, this pipe is copper, this beam is steel — so an inspector can check
compatibility at a glance without physically testing the material every
single time. Primitive types are these stamps on your data: `string`,
`number`, `boolean` tell TypeScript at a glance what's allowed to connect
to what.
